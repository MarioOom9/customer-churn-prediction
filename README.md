# Customer Churn Prediction

## Project Overview

This project predicts customer churn for a telecommunications company using machine learning.

The analysis includes data cleaning, exploratory data analysis (EDA), feature engineering, model training, and performance evaluation.

---

## Dataset

Telco Customer Churn Dataset

Records: 7043 customers

Target Variable:
- Churn

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Data Encoding
6. Train-Test Split
7. Logistic Regression Model
8. Model Evaluation

---

## Model Performance

- Accuracy: 80.62%
- Precision: 65.93%
- Recall: 55.88%
- F1 Score: 60.49%

---

## Key Insights

- Contract type strongly affects customer churn.
- Monthly charges influence customer retention.
- Customers with shorter tenure are more likely to churn.
- Long-term contracts reduce churn risk.
